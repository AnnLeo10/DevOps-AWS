# DevOps--AWS

## AWS CodePipeline Integration with GitHub

This repository is created to demonstrate the integration of GitHub with AWS Developer Tools and understand the fundamentals of DevOps workflows.

### 🎯 Objectives

- Integrate a GitHub repository with AWS CodePipeline.
- Understand source control and repository management.
- Learn how code changes can trigger automated pipeline executions.
- Explore the fundamentals of Continuous Integration and Continuous Delivery (CI/CD).

### 🛠️ Technologies Used

- **GitHub** — Source code management and version control
- **AWS CodePipeline** — Automated pipeline orchestration
- **Git** — Version control through command-line operations
- **AWS Developer Tools** — Integration with development workflows

### ⚙️ Workflow

1. Create a repository on GitHub.
2. Establish a connection between GitHub and AWS.
3. Configure AWS CodePipeline to use the GitHub repository as its source.
4. Select the repository and branch.
5. Configure optional build, test, and deployment stages as required.
6. Monitor pipeline executions when code changes are detected.

### 📚 Learning Outcomes

- Understanding GitHub–AWS integration.
- Learning the role of AWS CodePipeline in automating development workflows.
- Understanding source stages and pipeline configuration.
- Exploring how version control supports DevOps practices.
